AsyncAPI support, better search, and cleaner teardown API Reference now treats AsyncAPI documents as first-class citizens alongside OpenAPI, with clearer badges, download labels, and improved search across polymorphic schemas. Added AsyncAPI badges and a Download AsyncAPI Document action. Improved search ranking for parameters, request bodies, and model fields, including oneOf, anyOf, and allOf schemas.
