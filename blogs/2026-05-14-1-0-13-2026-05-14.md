Scalar Client 1.0 — team workspaces, registry sync, conflict resolution, and a rebuilt experience Intro walkthrough — What's new in Scalar Client 1.0 Scalar Client 1.0 is the first major release of the open-source HTTP client as a focused desktop and web app. Workspaces are now built around teams and the Scalar Registry: you can sync in real time, resolve conflicts when edits diverge, and manage API descriptions and versions without leaving the client. Local workspaces stay fast and offline-friendly with explicit save and revert before anything ships upstream.
