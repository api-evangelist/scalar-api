Custom fetch support and clearer schema examples You can now pass a custom fetch implementation through API Reference configuration so Test Request calls honor options like credentials. Schema examples also render more reliably for null, whitespace-only, and value or externalValue shapes. Added customFetch configuration and deprecated the previous fetch option with an automatic migration path.
